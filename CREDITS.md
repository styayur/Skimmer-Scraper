## Project code and generated art

The Blender district, loft profiles, materials, GLB, procedural tower library and
inverted city geometry introduced for v0.7 are original work licensed under
AGPL-3.0-only. Blender 5.2.4 generated the reference scene and Cycles renders. The three bridge spans share an original metre-scaled Geometry Nodes group.
The game builds its meshes from the same profiles. The source and generation
instructions are in [art/district](art/district/README.md).

The five Sky Journey palettes/parameter profiles, inversion choreography and fifth-sky
light sculpture/signature are original procedural work. No third-party models, world
generation service, textures or runtime dependencies were added for this feature.

- Skimmer-Scraper source code and original procedural world/aircraft geometry: AGPL-3.0-only for v0.3 onward; historical MIT grants retained, © 2026 styayur.
- Sky, facade textures, signage, blossom, particles, aircraft materials, engine sound and wind noise
  are generated at runtime by this repository. Imported GLB files remain user-owned local data and are
  not shipped with the game. The aircraft and four world test fixtures are original assets.
- src/audio/synth.ts contains an original WebAudio engine/wind synthesis graph; no audio recordings are
  bundled.

## Research references

The static and animated world test scenes in `tests/fixtures/worldGlb.ts`
are original synthetic fixtures. Compatibility checks also used Khronos glTF
Sample Assets. BoxVertexColors and MeshoptCube are CC0. CarConcept is CC BY 4.0
and credited to DGG and Eric Chadwick in its upstream metadata. These sample
files were used locally for verification. [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea)

Engine and wind sounds are synthesized locally from original project code.
Optional DeepSeek speech uses the provider's HTTPS endpoints. Release testing
used locally generated Windows speech fixtures for scout commands.
Companion clips use original project scripts, rendered offline with Flite 2.2, the CMU US SLT voice trained on the CMU ARCTIC corpus, and opus-tools. The voice corpus permits commercial use and distribution with attribution. See [voice license](licenses/CMU-ARCTIC-SLT.txt) and [render source](art/radio/render.py).

The v0.3 model planner adapter, validator, Trust/Relay rules and relay line effect
are original repository code; no external AI/steering SDK or hosted proxy was added.
Paid evidence uses DeepSeek Flash/V4 Pro through its official HTTPS API with an
environment-only operator key. Runtime inference is optional and not bundled.

Fly Dangerous was inspected at README `fd481fa5a99632e706e1920a4723e08ff5dd24f1`:
its code is GPLv3 and its original assets are CC BY-NC-SA 4.0. Its assets, branding,
logo, code and sound were not copied. Only public product concepts informed the
independently authored control/peripheral design here.

v0.3 flight controls, shield, autonomous steering, instanced companion geometry
and HUD are independently authored here. No source, models or audio from Fly
Dangerous or Superflight are included; no robotics/steering library was added.

These works informed product and engineering decisions. Unless explicitly noted below, no code,
meshes, textures, shaders, audio or other assets from them are included here.

- **Skyward** by xpereta — <https://github.com/xpereta/skyward>. Studied arcade flight feel,
  deterministic pure simulation boundaries, chase-camera framing and procedural aircraft presentation.
  The repository exposes no reusable license at the time of review (license API returned 404).
  Therefore **no Skyward code, visuals or assets are copied or adapted**.
- **Neon Zenith** by Bill Chan — <https://github.com/billpwchan/neon-zenith>. MIT source license;
  project assets retain separate terms. Studied vertical-city composition, instancing/LOD, facade
  grammar and CPU spatial indexing/height-query ideas. This project uses an independently designed
  chunked AABB + BVH nearest-surface adapter and does not copy Neon Zenith code or assets.
- **Sakura Fantasy** by Bill Chan — <https://github.com/billpwchan/sakura-fantasy>. MIT source
  license; project assets retain separate terms. Studied environment art direction: seasonal sakura
  color, atmospheric depth, water/lantern light and restrained UI. No code, textures, models, audio
  or other assets are copied.

See [docs/RESEARCH.md](docs/RESEARCH.md) for the concrete design conclusions and rejected shortcuts.

### Dragonspine

Crownback's skinned meshes, armature and wingbeat are original project assets licensed under AGPL-3.0-only. Run Blender 5.2.4 with `--background --python art/dragonspine/author_crownback.py` to rebuild the editable scene and the three glTF detail levels.

The generated terrain, normal map and landmarks are original Skimmer-Scraper assets under AGPL-3.0-only. The original realm assets remain in the corresponding v0.8.2 source. Windows dependency notices are collected from Cargo's resolved packages in src-tauri/desktop-notices.txt. The desktop application uses Microsoft Edge WebView2 Runtime. NSIS packages are unsigned unless the release report explicitly records a verified Authenticode signature.

The Windows world library downloads the official terrain archive with reqwest (MIT or Apache-2.0, https://github.com/seanmonstar/reqwest), stages it with tempfile (MIT or Apache-2.0, https://github.com/Stebalien/tempfile), reads ZIP entries with zip (MIT, https://github.com/zip-rs/zip2), and checks disk space through windows-sys (MIT or Apache-2.0, https://github.com/microsoft/windows-rs).

The native Windows folder picker uses rfd (MIT, https://github.com/PolyMeilex/rfd).
