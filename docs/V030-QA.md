## Opt-in genuine inference

```powershell
$env:EVIDENCE_PREFIX='phase-6'
node scripts/model-evidence.mjs
node scripts/cooperation-evidence.mjs
node --use-env-proxy scripts/relay-model-evidence.mjs
npm run release:privacy
```

These are paid calls requiring an operator-provided `DEEPSEEK_API_KEY` environment
variable, outside ordinary CI. The first script uses browser RAM and official
HTTPS; it saves sanitized state/decisions/usage without tracing/video or headers.
Disconnect/reload forgets the key. Current-page scripts can access runtime keys.

The comparison replays a genuine decision with fresh IDs against fixed FOLLOW and
no-companion controls. The Relay experiment uses a synthetic HOLD setup over
actual geometry, earns Trust by leading, pauses for official inference, then
replays the unmodified action with fresh IDs. It reports observed refusals or
failures too. It does not prove live-latency rescue or general model superiority.

## Packaging and promotion

From a clean verified commit, build twice with the same lockfile/toolchain and
compare all dist hashes. `python scripts/package-release.py <output-dir>` creates
sorted, fixed-commit-time static/source ZIPs, a manifest and SHA256SUMS. The source
ZIP includes `SOURCE_REVISION.json` for rebuilding outside Git. Optional historical
screenshots/decisions remain at the linked commit. Archives exclude environment
files, node_modules, user models and private browser storage. Cross-OS binary
identity is not claimed.

Keep v0.3.0-rc.1 a prerelease and v0.2.0 the public game until the transition spike
and subjective controls/art/AI teamwork are reviewed. Reproduce long WORLD_SWAP
frames with `journey-evidence.mjs` after the upward520m crossing. Also exercise
skip, reduced rotation, three views, narrow bridges and rapid retries. Physical
gamepad feel/haptics and Safari/mobile GPUs are outside this operator's equipment.
