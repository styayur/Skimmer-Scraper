# Skimmer-Scraper 0.6.0

Explore a continuous mirrored sky and a city that prepares flight corridors before the aircraft arrives. The title opens directly into play or the searchable in-game guide. Settings link back to the corresponding tutorial sections.

- **Worlds.** A continuous atmospheric ground plane connects the inverted skyline visually. High-speed flight forecasts upcoming chunks while keeping collision coverage, wingmates and the nearby view ahead of speculative work.
- **Local GLB cities.** Generate a fresh layout, keep a favorite or copy one portable seed. Replaying a copied layout uses the original GLB and restores its import settings and collision geometry.
- **Companion radio.** Wingmates speak through the system voices by default. Adjust speaking volume and preview each role. Opt in to local Mandarin Kokoro on compatible WebGPU hardware. The browser downloads about 177 MB of model weights on first use and can resume downloads. Windows Firefox uses system speech or subtitles.
- **DeepSeek.** Push-to-talk and model speech remain optional. A personal API key enables transcription, validated flight instructions and streamed spoken replies.
