# Background music

Music starts on first takeoff at 35% volume. Advanced settings save the music switch and volume on this device. Selected local files last for the current window. The music pauses with flight, changes pools on world selection and ducks during radio transmissions. Local files remain in this window and take precedence over its bundled pool.

The Web and Windows players share an HTML audio session. Each window owns its media element and object URLs. Closing the game releases them without contacting another mzk or mpv process.

The selector ports the literal Unicode scoring, quality threshold, shortlist and exponential weighting from [mzk](https://github.com/styayur/mzk/blob/3c6b9414fd6d43e01822d36e7d875f7c7db1b1cf/src/matching.rs). Curated world pools constrain the candidates before matching. The MIT notice applies to the selection code. No external music provider is configured.

The eight instrumental recordings are project originals composed with sine oscillators, deterministic voicings and envelopes. Rebuild them using Python, NumPy and opus-tools with `python art/music/compose.py`. The game ships the rendered files and does not require the authoring tools.
