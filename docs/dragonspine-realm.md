# 龙脊幻境

按 G 打开世界窗口，选择「龙脊幻境」。输入种子并点击「生成并重载」。种子 334458 的起始峡谷向北穿过石拱。两侧的山脊挡住低空航线，抬高机头可进入云层上方的龙巢和浮岛。相同种子使用相同地形和地标坐标。世界选择不会覆盖旧版城市链接或成绩。

铜冠龙使用 Blender 原创模型。翼根和尾部独立动画，近距离身体、颈部、翅膀和尾部使用简化动态碰撞体。远距离使用滑翔剪影。高画质另显示一条远景龙。飞行时按 Esc 或手柄暂停键打开菜单。高级飞行设置中的「快速」缩短翻转动画，等待新世界碰撞与安全航道的步骤仍会执行。第五次穿越的解锁记录可在教程中查看。

## 桌面高精度包

解压世界包，打开世界窗口的「高精度世界包」，选择直接包含 `world-pack.json` 的文件夹。全部分块校验通过后，点击「进入世界」。相同 ID 的新资源包会在成功安装后替换旧版。取消或校验失败时仍可使用原包。「移除副本」释放应用资源库的空间。原始目录由玩家管理。

版本 1 的高精度包覆盖种子 334458 的 100 个 220 米地形块。超出覆盖范围时继续生成基础地形。网页版从同源静态资源读取中等精度，桌面版额外按需从本地数据库读取近景。不安装大型资源包也可以起飞。

## 资产重建

在仓库根目录使用 Blender 5.2.4 运行 `blender --background --python-exit-code 1 --python art/dragonspine/author_dragon.py`，生成可编辑场景、动画 GLB、远景 GLB 与预览。使用支持 TypeScript 类型剥离的 Node 运行 `node scripts/build-dragon-pack.mjs public/realms/dragonspine/web web` 或 `node scripts/build-dragon-pack.mjs <空输出目录> high`。使用独立输出目录保存高精度包。

建模脚本、Geometry Nodes、模型、预览与生成的地形采用项目的 AGPL-3.0-only 许可证。
