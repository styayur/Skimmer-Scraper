# Skimmer-Scraper v0.1.0

The first public release candidate of a close-surface 3D flight challenge through an original
sakura-dusk megacity.

## Play

- GitHub Pages preview: https://styayur.github.io/Skimmer-Scraper/
- Cloudflare Pages production: configured but blocked on account authorization; not claimed live.

## Highlights

- Keyboard flight with a 120 Hz deterministic simulation and responsive chase camera.
- Five-second surface grace, exact BVH surface-distance queries, impact and grace-expiry failures.
- Local best and instant retry with no account.
- Local-only GLB aircraft import, persistence, rotation and removal.
- Original procedural city, aircraft, textures, signage, particles and synthesized audio.
- WebGL2 checks, responsive title/HUD and explicit unsupported-renderer fallback.

## Verification

- 22 Vitest unit/integration tests.
- 5 Playwright browser tests across desktop/mobile, rules, local GLB import and WebGL2 fallback.
- JSON acceptance reports and screenshots under `acceptance/` and `evidence/`.
- CI/headless rendering uses SwiftShader; real-GPU performance is not certified in this release.

See `CHANGELOG.md` and `docs/ACCEPTANCE.md` for known limitations.
